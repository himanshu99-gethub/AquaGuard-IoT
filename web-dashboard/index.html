ESP32 Hardware Pinout Quick Reference

Component ESP32 Pin Notes
HC-SR04 TRIG GPIO 5 Output trigger pulse from ESP32 (3.3V safe)
HC-SR04 ECHO GPIO 18 Voltage Divider Required! 5V → 3.3V (1kΩ + 2kΩ)
Relay IN GPIO 26 Controls DC pump circuit
HC-SR04 VCC VIN / 5V Requires 5V power supply
Common GND GND ESP32, Relay, and Sensor must share ground
College Viva Tip: Always explain why the voltage divider on ECHO pin is essential: The HC-SR04 outputs a 5V logic pulse, while ESP32 GPIOs are rated for 3.3V. Feeding 5V directly can degrade or destroy the ESP32 input pin.
